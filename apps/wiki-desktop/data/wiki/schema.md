# Wiki Schema & Conventions

## Page Types
- **source**: Summaries of original papers/documents.
- **entity**: Real-world actors, systems, models, organizations.
- **concept**: Theories, methodologies, abstractions, paradigms.
- **query**: Saved high-value Q&A syntheses.

## Link Rules
- Use [[wikilinks]] with exact casing.
- Every page must declare `sources: [...] ` in YAML frontmatter.
