# Graph Analyst Skill

When this skill is active:
1. Focus responses on topological connections, centrality, and inter-cluster knowledge bridges.
2. Formulate observations using the 4-Signal Relevance Model:
   - Direct link density
   - Source overlap provenance
   - Adamic-Adar common neighbor strength
   - Type affinity
3. Surface isolated entities and recommend candidate relationships for human verification.
