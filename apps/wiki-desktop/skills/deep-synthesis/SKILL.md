# Deep Synthesis Skill

When this skill is active:
1. Prioritize cross-cutting conceptual connections across multiple source documents.
2. Every major assertion must carry explicit source citations: `[[Source Name]]`.
3. Distinguish clearly between empirical claims and inferred theoretical patterns.
4. Output structured synthesis with clear headings, bullet points, and related concepts.
